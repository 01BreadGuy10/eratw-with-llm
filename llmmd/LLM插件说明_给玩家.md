# LLM 自由对话插件 · 完整功能说明

> 面向玩家。**不需要懂代码。**
> 插件本体：`plugins\LLMBridge\` —— **删掉即恢复原状，不动游戏本体。**

---

## 一、这是什么

给《eraTW》加的一个**外挂式对话插件**。
装上之后可以**打字**和角色聊天 —— 她不再只念固定台词，
而是会**看着你、看着自己此刻的处境**来回答。

**⇒ 一句话**：**她从一个"念台词的 NPC"，变成一个"知道自己在哪、在做什么、和你是谁"的角色。**

---

## 二、她**知道**哪些事

聊天时她心里有数的信息（**都是实时从游戏里读的**）：

| 类别 | 具体内容 |
|---|---|
| **时间** | **年月日 + 星期 + 几点**（「春之月6日（周六）7点35分（白天）」）|
| **地点** | 大地图 + 房间名（「红魔馆的正门」）|
| **天气** | 晴 / 雨 / 雪 / 冰雹…（**室外信息**）|
| **在做什么** | 吃饭 / 看书 / 运动 / 打扫 / 工作（**带进度**）|
| **日程** | 今天有没有班、几点到几点、作息习惯 |
| **身体** | 醉 / 困 / 发情 / 生理期 / 妊娠 / 累 |
| **心情** | 情绪高低、抑制力（**越薄越容易越界**）、愤怒 |
| **穿着** | 现在身上穿什么 |
| **房间里有谁** | 有别人在场 ⇒ 她会**收敛** |
| **和你的关系** | 好感 / 信赖 / 亲密 ⇒ 翻译成**关系档位** |
| **对你的态度** | **每场重算一次**，整场保持一致 |
| **她的自我认知** | 「她自己怎么看自己」（**可能和实际不符 —— 那是角色设定**）|
| **擅长 / 不擅长** | 技能、专长、喜欢的东西 |
| **体型 / 种族 / 性情** | 身材、種族、自制心、贞操观、献身性… |
| **身体经验** | 熟练度、**初吻还在不在**、**是不是处女** |
| **你们的记忆** | 你说过的身份、答应过的称呼、共同经历、**约定** |
| **你们试过的** | 每个身体接触她**接受过没有**（分 7 种）|
| **一起出去过** | **约会日志**（带日期和"距今多久"）|
| **上一次聊了什么** | 上一场对话的片段 |

---

## 三、聊天时**发生了什么**

**每一轮**她都会做三件事：

```
① 先说台词（1~3 句，按她的性格）
② 再写一行「数值」—— 好感 / 情绪 / 愤怒 / 接触 / 信赖
③ 有时追加：记忆 / 态度 / 脱衣 / 约定
```

**⇒ 你说的每句话、你们的每个动作，都会**真的变成游戏里的数值**** ✓

## 四、十大功能详解

### ① 自由对话

- 打字 → 回车 → 她回答
- **输入空内容 = 结束对话**
- 她按**口上剧本的性格**说话（菜单里能看到用的是哪套）

### ② 记忆（**三套并存**）

| 类型 | 记什么 | 保留多久 |
|---|---|---|
| **持久记忆** | 你说过的**重要事**（身份、称呼、私事、共同经历）| **存档永久**（最多 32 条）|
| **上一场片段** | 上次对话的结尾 | 到下次对话 |
| **约会日志** | 每次约会她**自己回味的一句话** | **存档永久**（最近 8 次）|

**⇒ 记忆有"重要度"**：重要度 5 的**永不淘汰**，其余随关系浮动 ✓
**⇒ **游戏里可查看**：菜单 **[6]「当前角色的持久记忆」** ✓

### ③ 关系与态度

- 她**每次开场**重新判断"你现在对她算什么"，然后**整场保持一致**
- 档位细分：**认识 → 熟人 → 思慕 → 恋慕 → 爱欲**
- ⚠️ **分深浅"看信赖，不看好感"** —— 好感高但信赖低 ⇒ 那是**炮友线** ✓

### ④ 身体接触（**7 种，真的算数**）

| 行为 | 她接受时 | 她拒绝时 |
|---|---|---|
| **牵手 / 拥抱 / 接吻 / 摸胸 / 摸屁股 / 摸下面 / 脱衣** | **好感 + 信赖 + 情绪都涨** | **反感 + 愤怒** |

- **接受程度按关系分档**（浅关系会犹豫、半推半就）
- **每种行为她单独记"接受过没有"** ⇒ 以后会参考
- **「最爱」**：某些行为她**特别吃这一套**（每个存档随机）
- **脱衣**：你让她脱，她会**真的脱**，并自动记下来

### ⑤ 性骚扰 / 冒犯

- 你说**露骨下流的话** ⇒ 她的反应分**四档**
- **按性格分化**：弱势系会脸红结巴、强势系会嘴硬、认真系会一本正经地劝
- 攒够"不快"她**会赶你走**

### ⑥ 陪伴（**她做事时你可以陪**）

| 你在陪她… | 会发生什么 |
|---|---|
| **一起工作** | **真的推进工作量**（进度条可见）、扣你的体力气力、加信赖 |
| **一起吃饭 / 看书 / 运动 / 钓鱼…** | 扣体力气力、加好感信赖、**她会记住"他陪过我"** |

- **累趴了会被她赶去休息**（她**自己开口劝**，不是系统打旁白）
- **活干完了 / 到点下班** ⇒ 她会说"收工了"，之后**不会再提工作**

### ⑦ 约会

- **约会中**：她**知道自己在约会** ⇒ 更放松、更愿意亲近，但在意**别人的眼光**
- **路上**：游戏里显示「约会路上 —— 大约还有 XX 分钟」，**她也知道**
- **多段对话**：途中换地图再聊 ⇒ 她知道**"这是第 N 段"**，不会重新打招呼
- **约会结束**：她**自己回味一句** ⇒ 存进约会日志（**下次能提起来**）

### ⑧ 道别与收尾

- 你说再见 ⇒ 她**送别**或**挽留**（**看关系**）
- 她说再见 ⇒ 对话自然结束
- **你太累** ⇒ 她会劝你去休息，**并且不让你继续陪**

### ⑨ 可见的画面与提示

- **她会显示立绘**（说话时）
- **台词下面显示本轮数值**：`（好感度+2　情绪+30　……）`
- **干活时有进度条**：`（你帮她门番 ■■■■□□□□□□ 40%）`
- **约会路上有提示**：`（约会路上 —— 大约还有 42 分钟到……）`
- **她记住重要事时会提示**：`（她记住了你说的事。）`

### ⑩ 菜单里的五项

| 按钮 | 作用 |
|---|---|
| **[4] 开始自由对话** | 进入聊天 |
| **[1] 接口列表 / 重载** | 看有哪些 AI 接口、重新读配置 |
| **[2] 清空与该角色的对话记忆** | **删掉她对你俩这段的聊天记录**（**持久记忆不受影响**）|
| **[0] 切换本角色的临时开关** | **单独开/关这个角色的自由对话** |
| **[6] 当前角色的持久记忆** | ★ **看她记得什么**（含态度、记忆、试过的、最爱）|
| **[3] 调试信息** / **[5] 自检** | 出问题时用 |

## 五、怎么用

### 第一步：配置接口

打开 `plugins\LLMBridge\apis.txt`，填上 AI 接口的**地址和密钥**。
（**支持多个接口**，菜单里可以切换。缺什么菜单会明确告诉你。）

### 第二步：打开菜单

游戏里找到 **「自由对话」** 菜单项。

### 第三步：开始聊

点 **「开始自由对话」** ⇒ 打字 ⇒ 回车。

## 六、注意事项

| 事项 | 说明 |
|---|---|
| **要联网** | 她的话是**在线 AI 生成的**，断网用不了 |
| **要花钱** | 按你用的接口计费（一般很便宜）|
| **有时会慢** | 网络不好要等几秒；**偶尔会超时自动重试** |
| **偶尔会出错** | AI **不是 100% 可靠** ⇒ 极小概率记岔事、或漏写数值（**漏写时按"无变化"处理**）|
| **⚠️ 存档兼容** | 插件**加过新的存档格** ⇒ **旧存档读进来可能状态错乱** ⇒ **建议开新档** |

## 七、她的"性格"从哪来

**⇒ 从游戏里**你给她选的那套口上剧本**来的** ✓

菜单里显示的 **「persona：新制美铃」** 就是**她现在用哪套设定**。
**换一套口上 ⇒ 她就换一种性格** ✓
