### A. 快感值系统（**核心**）

**① 走官方 `CUP` 路线**（`LLM_INTIMATE.ERB:188` 等 5 处）

- 官方设计是「动作加 `CUP` ⇒ 回合末汇总到 `PALAM` ⇒ UI 读 `PALAM`」

判据：`TEQUIP:上半身/下半身着衣状況 == 0` + `EQUIP:上半身/下半身内衣`

**③ 手动汇总 `CUP → PALAM`**（`:262~283`）
```erb
PALAM:快X += CUP:快X - CDOWN:X
CUP:快X = 0
CDOWN:X = 0
```
⚠️ **这一条是「官方计量槽联动」的关键** —— 不加的话官方 UI 永远看不到

**④ 部位下标**：`0=Ｃ 1=Ｖ 2=Ａ 3=Ｂ 4=Ｍ`

### B. 关键词判断（**不依赖模型**）

**⑤ `@LLM_INT_GUESS_BODY`**（`INTI:944`）
- 模型（deepseek-v4.1-Flash）**从不输出 `###BODY###`**（项目注释早记录）
- 所以改用**双方文本的关键词**判部位
- 调用点：`CONV:795~803`
```erb
IF LLM_MODE == 1 && STRLENS(LLM_BODY_TAG) < 4
    LLM_TMP = %LLM_INPUT%%LLM_OUT%       ← ★ 双方文本
```

## 二、⚠️ 已知坑（**踩过的**）

| # | 坑 | 教训 |
|---|---|---|
| **1** | **`read` 工具显示的行首 `[ ]` 是装饰** | **文件里不能有方括号** ⇒ 误写会 **Lv1 错误 ⇒ 整个函数不注册 ⇒ CALL 静默失效** |
| **2** | **`%数值变量%` 报 Lv2** | **数值要用 `{变量}`，字符串才用 `%变量%`** |
| **3** | **`SIF` 只绑一行，不能连续** | 自查脚本会报；连续/嵌套时必须用 `IF/ENDIF` |
| **4** | **`!= ""` 判不出 `""`** | **用 `STRLENS(...) >= 4`** |
| **5** | **`#DIMS` vs `#DIM`** | **字符串用 `#DIMS`，数值用 `#DIM`**（`++`/`>` 会报错） |
| **6** | **`@LLM_APPLY_DELTA` 看不到主循环变量** | 跨函数要**传参**或在**调用方**处理 |
| **7** | **自由互动不走官方回合** ⇒ **`CUP` 不汇总** | **必须手动汇总** |
| **8** | **`PRINT_FIGURE` 是追加** | **重复调用会叠两个立绘** ⇒ 不要重复画 |
