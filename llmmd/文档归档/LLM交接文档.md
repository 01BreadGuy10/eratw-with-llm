## 2. ⚠️⚠️ 必读：2026-09-16 的事故

### 出了什么事

**一条 Python 脚本把 `LLM_CONVERSATION.ERB` 截断了** —— 从中间开始、前 2116 行丢失，
**30 个函数消失**（含**主循环 `@LLM_CHAT_LOOP`**）。

### 根因（**引以为戒**）

```python
out = []                      # ← ★ 空列表！
while i < len(lines):
    ...
    out.append(lines[i])
lines = out                   # ← 前半部分（lines[:fn]）从来没被复制进去
```

### 恢复过程

1. **用户手上有一份备份**（`E:\Program Files (x86)\back\eratw-sub-modding-main`，9/14 版）
2. **合并**：`备份[1..493]`（= 文件头 + `@LLM_CHAT_LOOP` + `@LLM_POLL` + `@LLM_PERSONA_SNAPSHOT` + `@LLM_TONE_OF`）
   **+ 截断版全部** ⇒ 救回核心
3. **重建 13 个函数**（备份里没有的今天新增部分）
4. **逐个补齐"今天对 `@LLM_CHAT_LOOP` 的改动"**（5 处）

### 📌 由此定下的两条铁律

> **① 写文件的脚本，必须先构造完整的新内容再一次性写出。**
> **绝不能"边遍历边 append 到空列表"** —— 一旦忘了复制前缀就截断。
> **⇒ 正确写法：`new = lines[:]` 然后改 `new`。**
>
> **② 脚本里的锚点必须先用 `count()` 确认唯一性。**
> `next(...)` 只取**第一个**匹配 —— 如果锚点在文件里出现 2 次，就会改错地方。
> **⇒ 判断依据：本项目有大量"同一件事两处表达"，这是栽过 7 次的老坑。**
> **（2026-09-16 当天又因为这个坑把 prompt 注入段覆盖了一次，见 §7。）**

## 3. 🛠 12 项自动自查（**每次改完必跑**）

```powershell
python tool/llm_selfcheck.py
python tool/erb_check.py 'ERB\魔改内容\LLM_CONVERSATION.ERB'
python tool/erb_check.py 'ERB\魔改内容\LLM_CHAT_BRIDGE.ERB'
```

### 12 项是什么

| # | 检查 | 抓什么 |
|---|---|---|
| 1 | 引号 / `%` 配平 | 词法错误 |
| 2 | **`SIF` 只绑一行** | 只数**直接子行**（缩进恰好 +1）|
| 3 | `@"…"` 里不能有裸 ASCII 双引号 | **写中文引号时必须用「」**|
| 4 | 跨函数变量 | 「声明在 A 却用在 B」|
| 5 | 容量 | 只报"写了 SIZE 却不够"|
| 6 | `%…%` 里的数值变量 | 数值必须用 `{…}` |
| 7 | 行首合法性 | 注释必须 `;` 开头 |
| 8 | 未声明左值 | 把 `.ERH` 全局 + ERB 内置变量算进去 |
| 9 | **`CHARADATA` 下标层数** | **`CHARADATA` 变量自己占一层下标** ⇒ 最多两层 |
| 10 | **调用签名** | 调用参数**多于**定义 ⇒ 游戏会报「参数过多」并停 |
| 11 | **`SIF` 套 `SIF`** | 游戏报 `Lv2: SIF的下一行"SIF"不能作为作用域` |
| 12 | **变量三列**（跨文件）| **只有读、从没写** ⇒ 分支永远不成立（静默失效）|

### ⚠️ 第 9~12 项都是**踩坑之后补的** —— 它们的价值

- **第 9 项**：`LLM_MEMO:(角色):LOCAL:1` 三层下标 ⇒ 游戏报"参数过多"
- **第 10 项**：重建后 `@LLM_CHAT_LOOP` 用**旧签名**调 `@LLM_PARSE_DELTA`（4 个出参 vs 6 个）⇒ 游戏停
- **第 11 项**：`SIF A` / `SIF B` 嵌套 ⇒ 游戏停
- **第 12 项**：**一次抓出 4 个真缺口**（见 §4 的"审计"）

### 第 12 项的误报控制（**改它时要小心**）

白名单 + **只报"读了 ≥ 2 次"**的：
- **形参**（多行签名会漏判）· **`#DIM CONST` 常量数组** · **引用传递回填**（`CALL f(..., VAR)`）· 调试变量
- **⇒ 真缺口都是"被当条件用的"，必然读不止一次** ✓

⚠️ **共同点：`.ERH` 里声明了、读的地方也在，但"写"的那一处丢了** ⇒ **静默失效**。

| 变量 | 后果 | 修法 |
|---|---|---|
| **`LLM_BYE_KEPT`** | 挽留可以**无限次** | 挽留成功时 `= 1` |
| **`LLM_WANT_SLEEP`** | **「她会主动收尾去睡」整块失效** | 用 `@LLM_IS_SLEEPTIME` + 50% 掷骰 |

## 5. 关键机制速查

### 架构：两阶段

```
判定阶段  @LLM_SLEEP_CHECK / @LLM_BYE_CHECK / @LLM_TOO_TIRED
          ⇒ @LLM_DECIDE_ACTION 算出唯一的 LLM_ACTION
对话阶段  @LLM_ACTION_HINT ⇒ @LLM_BUILD_SYSTEM_PROMPT ⇒ 模型
结算阶段  @LLM_PARSE_DELTA / @LLM_PARSE_MEMO / @LLM_PARSE_NOTE ⇒ @LLM_APPLY_DELTA
```

### 模型输出的**七个标记**

| 标记 | 解析函数 | 用途 |
|---|---|---|
| `###DELTA###` | `@LLM_PARSE_DELTA` | `a,b,c,t,tr,act`（6 个数）|
| `###MEMO### [N] …` | `@LLM_PARSE_MEMO` | 长期记忆（N=重要度 1~5，5 永不丢）|
| `###ADDR###` | `@LLM_PARSE_NOTE` | 他自报的身份 |
| `###PROMISE###` | `@LLM_PARSE_NOTE` | 你们说好的事 |
| `###CALL###` | `@LLM_PARSE_NOTE` | **她怎么叫他** |
| `###CALLHER###` | `@LLM_PARSE_NOTE` | **他怎么叫她** |
| `###STRIP###` | `@LLM_PARSE_NOTE` | **玩家要脱的那一件** |

**⚠️ 每个标记都必须"prompt 说明 + 解析 + 执行"三处齐全** —— 缺一处就是哑的（`###STRIP###` 就是这么被抓出来的）。

### `act` 编号（**改它要全局对齐**）

```
1 牵手  2 拥抱  3 接吻  4 摸胸  5 摸屁股  6 摸下面  7 脱衣服
```

**⇒ 改编号要同步改**：`@LLM_AGREE_NAME` / prompt 的 `act` 列表 / `LLM_D6 <= N` 守卫 /
`LLM_ACT > N` 范围 / `LLM_FAV <= N` / 所有 `FOR LOCAL, 1, N+1` / 注释。

### `LLM_AGREE` / `LLM_PREF` 的合意档位

```
0 = 没试过   1 = 拒绝过   2 = 接受   3 = 乐意
```
**⇒ 不用 `CFLAG:態度`** —— 那个是"总的"合意，**不区分行为**。

### 身体接触（t=5/6/7）的结算链

```
前置（睡眠/陪睡/工作/玩家气力/时间停止/1小时冷却）
  ⇒ LLM_TOUCH_OK = 0/1
  ⇒ ①气力双方 -30  ②SOURCE + LLM_SRC_ANY/LLM_TRST_ANY
  ⇒ ③按親密六档  ④按好感分段  ⑤反感判定
  ⇒ ⑦b 四档收益（親密 ≤5/≤10/>10 ⇒ 好感 30/50/80、信赖 20/30/50、欲求 5%/8%/12%）
  ⇒ ⑦c 好感直加 CFLAG:2  ⑦d 欲求+理性
⇒ ⑦e（独立一块，外层 IF LLM_D6 + IF LLM_TOUCH_OK 保护）
```

## 6. ERB 语法铁律（**踩过的**）

| 规则 | 说明 |
|---|---|
| **`SIF` 只绑紧随的一行** | **且不能配 `ELSE`/`ELSEIF`/`ENDIF`**；**下一行也不能是 `SIF`** |
| **`CHARADATA` 变量自己占一层下标** | 最多写 `VAR:(角色):(下标)`（两层）|
| **`#DIM CONST` 数组** | 声明时就赋值 ⇒ 不算"没写过" |
| **形参名不能叫内置名** | `CHARA` / `ARG` / `TARGET` / `LOCAL` / `TIME` / `RESULT`… 都不行 |
| **字符串拷贝用 `A = %B%`** | 裸写 `A = B` 得到字面量；`'=` 给 `#FUNCTIONS` |
| **`%…%` 只能装字符串** | 数值必须 `{…}` |
| **`@"…"` 里不能有裸 ASCII 双引号** | 用「」 |
| **`CALLNAME:xxx` 不能直接进 `%…%`** | 先用 `=` 接住 |
| **行首必须合法** | 注释必须 `;` 开头（**`>` 开头会让游戏拒绝启动**）|
| **`CALLSHARP` 同步阻塞、只回填最后一个参数** | `"0"`=等 / `"1"+文本`=成功 / `"-1"+原因`=失败 |
| **跨函数共享的变量必须放 `.ERH`** | 写在 `.ERB` 文件级会报 Lv1 |

**⚠️ `Lv1`/`Lv2` 警告只显示在屏幕上、不落盘** —— **必须靠用户截图** ⚠️
**⇒ 所以"改完让用户看启动画面"是固定流程。**

| **持久化** | 存档 → 重启 → 读档 → `[6]` | 值还在（**必须开新档**，旧档结构不匹配）|
| **道别** | 她说再见后随便回一句 | **对话退出**（`LLM_PENDING_EXIT`）|
| **超时重试** | 网络卡时 | `少女重连中（X/3）` |
