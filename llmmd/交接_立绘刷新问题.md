### 官方的「裸/服」判定链（**照抄这个就不会错**）

```erb
QOL_IMAGE.ERB:1008   IF 服装 == ""
QOL_IMAGE.ERB:1009       服装 '= CHECK_NUDE(CHARA) ? "裸" # "服"    ← 自动判

IMAGE.ERB:905   @CHECK_NUDE(CHARA)
:906   SIF FLAG:立絵種類 && !TEQUIP:CHARA:上半身着衣状況
:907       RETURNF 1                       ← 立绘模式：上身裸就算裸
:908   SIF !FLAG:立絵種類 && !TEQUIP:CHARA:上半身着衣状況 && !TEQUIP:CHARA:下半身着衣状況
:909       RETURNF 1                       ← 颜绘模式：上下都裸才算
:910   SIF BATHROOM(...) && !TFLAG:泡風呂
:911       RETURNF 1
:912   RETURNF 0
```

**⇒ 结论：`服装` 参数传 `""`，官方会自己判。传值反而覆盖它。**
