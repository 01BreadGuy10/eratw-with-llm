# 「陪伴」各动作的官方结算一览 —— 供数值设计

> 用途：给「陪她一起做××」的**动作专属分支**设计数值时对照用。
> 现状：除了 `0 发呆`（已定制），其余动作目前都**直接调用官方 `"ソース"` 分支**，
> 所以下表里写的官方行为**现在就已经生效**了。
>
> 出处：`ERB\MOVEMENTS\自由行動\FREE_ACT_*.ERB` 的 `CASE "ソース"`。

---

## 0. 前置知识（设计数值时会用到）

### 0.1 三个关键量

| 名字 | 含义 | 怎么来的 |
|---|---|---|
| `時間係数` | 收益倍率 | `MAX(投入時間 / 10, 1)`，投入時間 = `MIN(Activity_Duration, 30)`，即 **1~3** |
| `DOWNBASE:xxx += N * 時間係数` | **消耗** N× 系数（不是加！） | `DOWNBASE` 是"本次消耗"的累积量，之后统一扣 |
| `SOURCE:CHARA:xxx = N * 時間係数` | 写入情绪源，**由 `FAVOR_CALC` 在回合末换算成好感度/情緒** | 不是直接改数值 |

### 0.2 结果码 `TFLAG:193`

每个 `"ソース"` 分支都会设它，语义**逐动作不同**：

| 值 | 通用含义 |
|---|---|
| `1` | 大成功 |
| `0` | 成功 |
| `-1` | 失败（原因见动作表） |
| `-2` | 大失败（不会乐器 / 没钓竿） |

> ⚠️ `TFLAG:193` 是**全局共享**的（全项目 2331 处使用），
> 所以只能在 `"ソース"` 调用完**立刻**读，不能留着以后用。
> 官方的 `"付き合う"` 分支就是这么用的（`FREE_ACT_2.ERB:69` 的 `IF TFLAG:193 < 0`）。

### 0.3 官方**也可以**恢复

`12 休息` / `18 被炉` 用的是 `RECOVER_PERMIL(角色, 千分比, "体力"/"気力", 1)`
—— 按**上限的千分比**恢复。所以"恢复类"动作官方是有的，可以照抄这个函数。

## 1. 各动作一览

### 0 = 发呆想事情　✅ 已定制
- **官方**：信赖度 < `275 − 亲密×25` 时失败（双方气力 −40×系数）；否则成功（双方气力 **−20**×系数、`TFLAG:信頼度管理 = 1`）
- **结果码**：无（不设）
- **现状**：**不走官方** —— 改为气力 **+5**、`TFLAG:信頼度管理 = 2`
- **理由**：官方把"陪"理解为"找她搭话"，所以扣气力；而安静地一起发呆应该是**休息**
