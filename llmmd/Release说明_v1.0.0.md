# v1.0.0 —— LLM 自由对话 / 自由互动

> **首次正式发布。**
> 给《eraTW》加的外挂式对话插件：装上之后，你可以**打字**和她聊天 ——
> 她不再只念固定台词，而是会**看着你、看着自己此刻的处境**来回答。
>
> 插件本体在 `plugins\LLMBridge\` —— **删掉即恢复原状，不动游戏本体。**

---

## 一句话

> **她从一个「念台词的 NPC」，变成一个「知道自己在哪、在做什么、和你是谁」的角色。**

---

## 她**知道**哪些事

聊天时她心里有数的信息，**全部实时从游戏里读**：

| 类别 | 具体内容 |
|---|---|
| **时间** | 年月日 + 星期 + 几点（「春之月6日（周六）7点35分」） |
| **地点** | 大地图 + 房间名（如「红魔馆的正门」） |
| **天气** | 晴 / 雨 / 雪 / 冰雹（室外信息） |
| **在做什么** | 吃饭 / 看书 / 运动 / 打扫 / 工作（**带进度**） |
| **日程** | 今天有没有班、几点到几点、作息习惯 |
| **身体** | 醉 / 困 / 发情 / 生理期 / 妊娠 / 累 |
| **心情** | 情绪高低、抑制力、愤怒 |
| **穿着** | 现在身上穿什么（含**饰品 / 腕部 / 蝴蝶结**这类装饰件） |
| **在场的人** | 有别人在 ⇒ 她会**收敛** |
| **和你的关系** | 好感 / 信赖 / 亲密 ⇒ 翻译成**关系档位** |
| **对你的态度** | 每场重算一次，整场保持一致 |
| **她的自我认知** | 她怎么看自己（可能和实际不符 —— 那是角色设定） |
| **擅长 / 不擅长** | 技能、专长、喜欢的东西 |
| **体型 / 种族 / 性情** | 身材、种族、自制心、贞操观、献身性 |
| **身体经验** | 熟练度、初吻还在不在、是不是处女 |
| **你们的记忆** | 你说过的身份、答应过的称呼、共同经历、**约定** |
| **你们试过的** | 每种身体接触她接受过没有（分 7 种） |
| **一起出去过** | 约会日志（带日期和「距今多久」） |
| **上次聊了什么** | 上一场对话的片段 |

## 主要功能

- **自由对话（`30`）/ 自由互动（`31`）** —— 打字聊天，输入空内容即结束
- **记忆系统** —— 持久记忆（存档永久，最多 32 条）+ 上一场片段 + 约会日志
- **关系与态度** —— 认识 → 熟人 → 思慕 → 恋慕 → 爱欲（**看信赖，不看好感**）
- **身体接触 7 种** —— 牵手 / 拥抱 / 接吻 / 摸胸 / 摸屁股 / 摸下面 / 脱衣
  接受 ⇒ 好感 + 信赖 + 情绪；拒绝 ⇒ 反感 + 愤怒（**真的算进游戏数值**）
- **性骚扰 / 冒犯** —— 分四档反应，按性格分化；攒够不快她**会赶你走**
- **陪伴** —— 陪她工作会**真的推进工作量**（进度条可见）；累趴了**她自己开口劝你休息**
- **约会** —— 她知道自己在约会、知道是「第 N 段」，结束后**自己回味一句**存档
- **脱衣** —— 你让她脱，她会**真的脱**并自动记下来
- **睡姦 / 醉姦** —— 角色无意识时的特殊分支（**只用玩家输入判断**）
- **快感值系统** —— 走游戏原生 `CUP → PALAM` 路线，和官方数值联动

| # | 问题 | 状态 |
|---|---|---|
| **1** | **脱衣后立绘不更新** —— 以前脱了衣服立绘还是穿着的，得重开互动才刷新 | ✅ 修好（改用游戏自己的显示接口，和外面 Look 界面同一条路径） |
| **2** | **脱内裤总说「外面还穿着」** —— 蝴蝶结这类装饰件被误当成外衣，把自己挡住了 | ✅ 修好（装饰件不再算上下衣） |
| **3** | **欲求不满被理解成「心情不好」** —— 它实际是**想做爱的程度** | ✅ 修好（prompt 里写明是性欲，不是烦躁/走神） |
| **4** | **赤裸时聊无关的事** —— 人都脱光了却在聊天气 | ✅ 修好（赤裸 ⇒ 语境锁定为「前戏后期 / 已结束」） |
| **5** | **思考链泄漏** —— 大段内心分析被当成台词念出来 | ✅ 修好（收紧阈值 + 扩充特征词） |
| **6** | **穿着看不清** —— 只显示最外层，不知道身上还有什么能脱 | ✅ 修好（现在会列出装饰件） |

## 怎么用

### ① 配置接口

打开 `plugins\LLMBridge\apis.txt`，填上 AI 接口的**地址和密钥**。
支持**多个接口**，菜单里可以切换；缺什么菜单会明确告诉你。

### ② 打开菜单

游戏里找到 **「自由对话」** 菜单项。

### ③ 开始聊

点 **「开始自由对话」** ⇒ 打字 ⇒ 回车。

## 注意事项

| 事项 | 说明 |
|---|---|
| **要联网** | 她的话是**在线 AI 生成的**，断网用不了 |
| **要花钱** | 按你用的接口计费（一般很便宜） |
| **有时会慢** | 网络不好要等几秒；偶尔超时后会自动重试 |
| **偶尔会出错** | AI 不是 100% 可靠 ⇒ 极小概率记岔事或漏写数值（漏写按「无变化」处理） |
| **⚠️ 存档兼容** | 插件加过新的存档格 ⇒ **旧存档读进来可能状态错乱** ⇒ **建议开新档** |
| **可随时卸载** | 删掉 `plugins\LLMBridge\` 即恢复原状，游戏本体不受影响 |

## 她的性格从哪来

**⇒ 从游戏里你给她选的那套口上剧本来的** ✓

菜单里显示的 **「persona：新制美铃」** 就是她现在用哪套设定。
**换一套口上 ⇒ 她就换一种性格** ✓
