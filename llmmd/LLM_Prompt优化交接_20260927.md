## 本次目标

针对 OOC 做了第一轮结构化优化：

- 让角色优先读取当前位置、当前行动、当前意识/身体状态；
- 把当前状态集中到 prompt 最末的「最终场景卡」；
- 让事实和行动分开；
- 压缩重复的 DELTA / MEMO / 关系性格提示；
- 保持自由对话、自由互动和持久记忆隔离。

## 当前代码变更

### `ERB/魔改内容/LLM_CONVERSATION.ERB`

新增/保留的末尾场景卡：

```text
【最终场景卡｜本轮生成前必须优先读取】
地点
当前时间
当前正在做
当前情绪/身体状态
当前场合
当前特殊状态
当前意识
本轮唯一主行动
```

最后场景卡要求：

- 地点、时间、行动、意识状态优先于历史冲突；
- 事实不是要逐条念出的清单；
- 先从当前地点和当前意识/身体状态入手，再回应玩家输入；
- 不要推进玩家没有做出的下一步；
- 互动模式使用 `（）` 写动作/环境，使用 `「」` 写角色台词。

### Prompt 瘦身

已压缩：

1. `###DELTA###` 规则和重复示例；
2. 长期记忆规则和重复类别说明；
3. 关系/性格重复说明；
4. 中段重复的当前事实优先级说明。

修正：

- 普通 DELTA 示例统一为六字段：`0,0,0,0,0,0`；
- 删除了没有 `[N]` 的错误 MEMO 示例；
- 保留 `###MEMO### [N]` 的合法格式；
- 没有删除解析协议或状态来源。
