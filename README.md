# eraTW × LLM —— 让角色真的会说话

> 这个版本给 eraTW（东方 Project 同人游戏「画蛇添足」）加了一层 **大语言模型驱动** 的自由对话。
> 角色不再是念预设台词，而是**按她自己的性格、当前处境、和你们的关系**实时生成回答。
>
> ⚠️ **本文是玩家向说明**。开发者向的说明见 `README.dev.zh.md` 和 `llmmd/` 目录。

## 一、这是什么

**eraTW** 是东方 Project 的同人文字游戏（**era 系文字游戏**），核心玩法是：

- 你在幻想乡各处走动，和**上百个东方角色**互动；
- 每个角色有**好感度 / 信赖度 / 情绪 / 体力**等数值；
- 可以**聊天、送礼、帮忙干活、约会**，关系深了还能更进一步；
- **原版的对话是预设文本** —— 每个角色有大量写好的口上（台词），但只能覆盖作者想到的情况。

**这个版本做了什么**：

> 把「她说什么」交给**大语言模型**实时生成。

于是她能：

- 知道你**现在在哪、几点、天气如何**；
- 知道你**刚才在干什么、累不累**；
- 记得**你告诉过她的事**（跨对话）；
- 按**她的性格**说话（嘴硬的照样嘴硬、无口的照样话少）；
- 关系变了，**态度也跟着变** —— 但不会变成另一个人。

## 二、怎么装自己的 API（重要）

### 2.1 你需要什么

**一个 OpenAI 兼容接口的 API key。** 常见选择：

| 服务商 | 说明 |
|---|---|
| **DeepSeek** | 便宜、中文好，最常用 |
| **OpenAI / Kimi / 通义 / 硅基流动** 等 | 任何 OpenAI 兼容接口都行 |
| **本地 Ollama / LM Studio / vLLM** | 不需要 key，但要自己跑模型 |

**⚠️ 这个版本不带 key** —— 你必须自己填。**没有 key 时对话功能不会启动**（不影响游戏本体）。

### 2.2 三步装好

#### 第 1 步：复制模板

在游戏目录找到：

```
plugins\LLMBridge\
```

里面有一个 **`apis.txt.example`**（模板）。**把它复制一份、改名成 `apis.txt`**：

```
plugins\LLMBridge\apis.txt.example   →   plugins\LLMBridge\apis.txt
```

> ⚠️ **必须叫 `apis.txt`**（去掉 `.example`），插件只认这个名字。

#### 第 2 步：填你的 key

用记事本打开 `apis.txt`，找到带 `key =` 的那几行，把值改成你自己的：

```ini
[我的接口]
key    = sk-你的密钥
model  = deepseek-chat
url    = https://api.deepseek.com
```

**只有三个字段是必须的**：

| 字段 | 填什么 |
|---|---|
| **`key`** | **你的 API 密钥**（本地 Ollama 不需要，可留空或写 `none`）|
| **`model`** | **模型名**（以服务商文档为准，如 `deepseek-chat`）|
| **`url`** | **接口地址**（见下）|

**`url` 的写法很宽松**，下面这些都能识别：

```ini
url = https://api.deepseek.com
url = https://api.deepseek.com/v1
url = https://api.deepseek.com/v1/chat/completions    ← 直接粘贴完整地址也行
url = api.deepseek.com                                ← 不带 https:// 也能识别
url = http://127.0.0.1:11434                          ← 本地 Ollama
```

**⇒ 插件会自动补全成 `.../v1/chat/completions`**，不用你操心。

#### 第 3 步：启动游戏

双击 **`Emuera_skiaV10_x64.exe`**。

**⇒ 改完 `apis.txt` 保存即生效** —— 不用重启游戏（配置会热重载）。

### 2.3 加多条 / 切换用哪条

**可以加很多条**，格式就是重复一段：

```ini
[DeepSeek]
key   = sk-aaa
model = deepseek-chat
url   = https://api.deepseek.com

[本地 Ollama]
key   = none
model = qwen2.5:7b
url   = http://127.0.0.1:11434
```

**切换当前用的那条**，三种方式都行：

```ini
[*]                      ← 星号表示「选这条」
```
```ini
active = DeepSeek        ← 按名字选
```
**或者在游戏内用菜单切换**（会写回本文件）。

**⇒ 不标的话，默认用第一条。**

### 2.4 可选字段

```ini
type        = openai        ; 接口风格，默认就是 openai，一般不用写
temperature = 0.65          ; 0~2，默认 0.8。想更像角色本人可调 0.6~0.9
max_tokens  = 2000          ; 单次回复上限，默认 400。太短会被截断
```

**⇒ 建议 `max_tokens` 给 2000 以上** —— 太短会导致回复被切断。

## 三、打个招呼：怎么开始对话

1. **走到角色面前**（必须是同房间）；
2. **打开指令菜单**，往下找；
3. 你会看到两个按钮：

| 按钮 | 作用 |
|---|---|
| **自由对话** | **日常聊天** —— 说话、陪着干活、约会 |
| **自由对话 ★** | 同上（**★ = 这个角色已开启**）|
| **自由互动 ★** | **亲密场景** —— 只在特定状态出现（见下）|

> **⚠️ 没开这个角色时不会显示按钮** —— 去 `config.txt` 里加 `no:N = 1,1`。

4. **点进去**，直接打字说话，回车发送；
5. **输入空内容即结束对话**。

### 关于「自由互动」

**⇒ 这个按钮只在下面情况出现**：

- 她**睡着了**（睡眠中）；
- 她**喝醉了**（烂醉）；
- 或者你们**已经是那种关系**（诶嘿嘿）。

**⇒ 平时不会出现** —— 关系没到就没有。

## 四、LLM 部分能做什么

### 4.1 她「感知」得到的东西

每一轮对话，她都会收到一份**当前状态**：

| 她知道什么 | 例子 |
|---|---|
| **现在在哪** | 「红魔馆 · 地下室的走廊」 |
| **现在几点 / 今天几号** | 「10月7日（周三）· 深夜」 |
| **外面什么天气** | 「下着小雨」 |
| **同一个房间里还有谁** | 「魔理沙也在」 |
| **你刚才在做什么** | 「你正在钓鱼（还剩一半多）」 |
| **她自己正在做什么** | 「正在打扫」 |
| **你累不累** | 「你快撑不住了」 |
| **你们什么关系** | 「恋人」「朋友（聊得来、信得过）」 |
| **你们之间发生过什么** | 「你们接过吻」 |
| **她自己的身体状态** | 「有点困了」「醉得厉害」 |
| **她自己的性格 / 说话方式** | 按角色表 + 官方数据 |

**⚠️ 关键设计**：她**不会**把这些逐条念出来 —— **那是背景，不是台词**。
她会挑和当前话题**最相关的一两点**自然带过。

### 4.2 她会记住你说过的事

**跨对话持久记忆**：

- 你**自报的身份**（「我现在是红魔馆的佣人了」）；
- 你们**说好的事**（「下次带酒来」）；
- 一个**特殊的称呼**（她叫你「姐姐」、你叫她「老板」）；
- 她**告诉过你的私事**。

**⇒ 重要性 5 的条目永不丢失**；其他条目会按关系深浅决定记不记得住。

### 4.3 关系会改变她的态度（但不会改变她这个人）

| 关系 | 表现 |
|---|---|
| **陌生** | 客气、有距离感、不主动 |
| **认识** | 正常聊，但不亲昵 |
| **思慕** | 有点在意你，偶尔走神 |
| **恋慕** | 会想多待一会儿、舍不得你走 |
| **恋人** | 主动、黏人 —— **但嘴硬的照样嘴硬** |

**⚠️ 设计原则**：关系只决定「能聊多深」，**不改变她的性格**。
不会因为关系变好，所有角色都变成同一种黏人甜腔。

### 4.4 她会陪着做事 / 让你帮忙

**自由对话里可以邀请她一起干活**：

- 一起**吃饭、看书、钓鱼、运动、打扫**；
- 她**会拒绝**（如果关系不够、或这件事太私密）；
- 答应了就**照抄官方的数值结算**（好感、信赖、体力、技能经验）。

**⚠️ 而且「活干完了就算下班」** —— 不用非等到排班的结束时间。

### 4.5 她会挽留你 / 赶你去休息

- **越亲密，越不想让你走**（恋人挽留率 80%）；
- **但到点该上班 / 该睡觉时，她自己也会推你走**；
- **你快撑不住时，她心疼你**，让你去休息。

### 4.6 亲密场景（自由互动）

**⇒ 只有三种情况会触发**：

| 场景 | 她的状态 | 她知道什么 |
|---|---|---|
| **睡姦** | **熟睡、完全没意识** | **听不到你说话** —— 只有睡梦中的反应 |
| **醉姦** | **醉得不省人事** | **听不清你说话** —— 只有含糊的醉话 |
| **诶嘿嘿** | **双方都清醒** | **正常听见、正常回应** |

**⚠️ 重要**：
- **睡姦/醉姦时，她不会回应你说的话** —— 因为**她根本不知道你在**；
- 你输入的话默认当作**心里想的 / 低声自言自语**；
- **这类场景不写持久记忆** —— 她醒来不会记得（除非真的醒了）。

**⇒ 界面下方会显示计量表**：

```
胸■■■□□□□□38  阴■□□□□□□□4  蒂□□□□□□□□0  臀□□□□□□□□0  口□□□□□□□□0  觉■■□□□□□□25
```

- **胸 / 阴 / 蒂 / 臀 / 口**：各部位的**快感累积**（满了会触发高潮）；
- **觉**：**觉醒值** —— 满了她会**骰一次是否惊醒**；
- **【半醒】** 标记：她**半梦半醒**（听得见一半、会认错人）。

**⇒ 觉醒判定和好感 / 信赖挂钩**：**越喜欢你越不容易醒** ✓

## 五、游戏本体是什么（粗略）

**⇒ 这部分是原版内容，不是我们加的**，简单说一下：

### 核心循环

```
你在地图上走动
  → 遇到角色
    → 互动（聊天 / 送礼 / 帮忙 / 约会）
      → 数值变化（好感 / 信赖 / 情绪）
        → 关系推进
          → 解锁新互动
```

### 主要数值

| 数值 | 含义 |
|---|---|
| **好感度** | 她喜不喜欢你（大数值，几千到上万）|
| **信赖度** | 她信不信得过你（稀有，涨得慢）|
| **情绪 / 愤怒** | 她此刻心情好不好 |
| **体力 / 气力** | 你的身体状况 |
| **欲求不满度** | 她的生理需求（0~100%+）|
| **亲密** | 她能接受到什么程度的身体接触 |

### 关系阶段

```
陌生人 → 认识 → 思慕 → 恋慕 → 恋人 / 炮友 / 爱欲
```

**⇒ 注意**：**「炮友」和「情人」是两个不同的值**，语义不一样。

### 时间与作息

- 游戏内**有时间流动**（一次对话推进几分钟）；
- 每个角色有**自己的作息**（几点上班、几点睡觉）；
- **她该上班时真的会去上班**、**该睡觉时会困**。

### 我们的改动 vs 原版

| 项 | 说明 |
|---|---|
| **原版** | 预设口上台词（作者写好的） |
| **本版新增** | **LLM 实时生成台词**（本 README 讲的部分）|
| **不影响** | **游戏本体玩法、数值、剧情、原版口上全都保留** |

**⇒ 删掉 `plugins\LLMBridge.dll` 就完全恢复原版** ✓

## 六、配置项说明

**文件**：`plugins\LLMBridge\config.txt`（同样从 `.example` 复制）

```ini
; ── 全局总开关 ──
enable_free_talk      = 1     ; 1 = 允许「自由对话」
enable_free_intimate  = 1     ; 1 = 允许「自由互动」
debug_log             = 0     ; 1 = 写调试日志（排错用，平时关掉）
scan_interval_ms      = 200   ; 配置热重载检查间隔（毫秒）

; ── 每角色开关 ──
default_talk_intimate = 0,0   ; 没列出的角色：<对话>,<互动>，默认都关
idx:1                 = 1,1   ; 按运行时索引（会随存档变）
no:11                 = 1,1   ; 按角色编号（稳定，推荐）
```

### `idx:` 和 `no:` 的区别

| 标识 | 含义 | 稳定性 |
|---|---|---|
| **`idx:N`** | **运行时索引**（存档里会变）| ⚠️ **不稳定** |
| **`no:N`** | **角色编号**（CSV 文件名）| **✅ 推荐** |

**常见编号**：

| no | 角色 |
|---|---|
| **1** | **博丽灵梦** |
| **11** | **雾雨魔理沙** |
| **16** | **蕾米莉亚** |
| **50** | **芙兰** |

**⇒ 默认全关** —— **只有你显式列出的角色才开**。

## 七、常见问题

### Q：对话没反应 / 按钮点了没东西

1. **检查 `apis.txt` 是否存在**（不是 `.example`）；
2. **检查 key 是否填了**；
3. **检查 `config.txt` 里那个角色是否开了**（`no:N = 1,1`）；
4. **看 `plugins\LLMBridge\debug.log`**（把 `debug_log` 设成 1 才会有）。

### Q：回复很慢

**⇒ 正常**，模型要几秒到十几秒。**接口速度取决于你的服务商**。

### Q：她说的话很奇怪 / 不像这个角色

- **`temperature` 调低一点**（0.6~0.8 更像角色本人）；
- **关系太浅时**她本来就会比较客气；
- **如果明显 OOC**，可以反馈 —— 这是我们在持续调的部分。

### Q：她记不住我说的话

- **关系浅时她本来就记不住**（官方设计）；
- **重要的事**（身份、约定、称呼）系统会**强制记住**；
- **闲聊、天气、心情**不会被记（那些过几轮就没意义）。

### Q：为什么她不知道自己在哪 / 说错地点

- **这是我们在持续修的部分**；
- 一般**重新进一次对话**就正常了。

### Q：自由互动按钮不出现

**⇒ 只在三种情况出现**：
1. 她**睡着了**；
2. 她**喝醉了**；
3. 你们**已经是那种关系**。

### Q：会不会影响存档 / 原版内容

**⇒ 不会** ✓

- **不修改任何原版文件**；
- **不写游戏存档**（除了它自己的记忆数据）；
- **删掉 `plugins\LLMBridge.dll` 就完全恢复原版**。

## 八、安全提醒

### ⚠️ 你的 API key

| 做法 | 说明 |
|---|---|
| ✅ **`apis.txt` 已被 `.gitignore` 忽略** | **不会进 Git 仓库** |
| ⚠️ **不要用 `git add -f apis.txt`** | **`-f` 会强制忽略 `.gitignore`** ⇒ **立刻泄漏** |
| ⚠️ **不要把 key 贴到聊天记录** | **包括 issue / 截图** |
| ⚠️ **万一泄漏 ⇒ 立刻去服务商后台轮换** | **改 `.gitignore` 只能防未来** |

### 关于 key 的隐私

- **key 只被插件读取用来发请求**；
- **不会写进游戏存档**；
- **不会出现在游戏画面里**；
- **`debug.log` 里的 key 是打码的**。

### 目录约定

```
plugins/LLMBridge/
├── apis.txt              ← ★ 你的 key（本地私有，已被 gitignore）
├── apis.txt.example      ← 模板（进仓库）
├── config.txt            ← ★ 你的开关设置（本地私有）
├── config.txt.example    ← 模板（进仓库）
└── debug.log             ← 调试日志（已被 gitignore）
```
